# TOEIC Study

## 1. Goal

- Target Score: 850+
- Next Test Date: 2026-10-31
- Main Study Areas: RC Grammar, Vocabulary, LC
- Current Focus: Part 5 기초 문법 및 어휘 보완

## 2. Study Strategy

- LC: 문제 풀이 → 스크립트 확인 → 받아쓰기 및 쉐도잉
- RC: 문법 개념 학습 → 문제 풀이 → 오답 분석
- Vocabulary: 단어 뜻과 문맥 속 쓰임 함께 정리
- Review: 틀린 문제를 주기적으로 다시 풀기


## 3. Notes

- 모르는 문제는 정답만 외우지 않고 오답 원인을 기록한다.
- 반복해서 틀리는 문법 유형을 별도로 관리한다.
- 정리한 문제는 일정 시간이 지난 뒤 다시 풀어본다.
