# TOEIC RC - 명사의 형태와 수량 표현

## 1. 명사의 자리

명사는 사람, 사물, 장소, 개념 등의 이름을 나타낸다.

### 명사가 올 수 있는 자리

| 위치 | 예문 | 설명 |
|---|---|---|
| 주어 자리 | **Employees** work hard. | 주어 |
| 목적어 자리 | We hired **employees**. | 목적어 |
| 보어 자리 | She is a **manager**. | 주격 보어 |
| 관사 뒤 | a **report** | 관사 뒤 명사 |
| 소유격 뒤 | our **company** | 소유격 뒤 명사 |
| 형용사 뒤 | useful **information** | 형용사 뒤 명사 |

### 명사 자리에 올 수 없는 품사

- 동사: 명사 자리에 동사원형이나 일반적인 동사 형태를 그대로 사용할 수 없다.
- 형용사: 명사를 꾸미는 형용사만으로 명사 자리를 채울 수 없다.

예시
- We need an **application**. (O)
- We need an **apply**. (X)
- This is an **important decision**. (O)
- This is an **important decide**. (X)

※ 동명사(-ing), 명사절 등은 명사처럼 문장 성분 역할을 할 수 있다.

---

## 2. 가산명사와 불가산명사

### 2-1. 가산명사 (Countable Noun)

하나, 둘처럼 개수를 셀 수 있는 명사이다.

| 구분 | 형태 | 예시 |
|---|---|---|
| 단수 | a/an + 명사 | a book, an employee |
| 복수 | 명사 + -(e)s 등 | books, employees |

예문
- We hired **an employee**.
- We hired **three employees**.
- She submitted **a report**.

### 2-2. 불가산명사 (Uncountable Noun)

일반적으로 개수를 직접 세지 않고 양이나 정도로 나타내는 명사이다.

| 특징 | 예시 |
|---|---|
| 일반적으로 a/an을 붙이지 않음 | information, equipment |
| 일반적으로 복수형 -s를 붙이지 않음 | advice, furniture |
| 단수 취급하는 동사와 함께 사용 | The equipment **is** new. |

토익에서 자주 나오는 불가산명사

- information: 정보
- equipment: 장비
- furniture: 가구
- advice: 조언
- luggage / baggage: 수하물
- traffic: 교통량
- research: 연구
- news: 뉴스
- money: 돈
- work: 일, 업무

예문
- We need more **information**.
- The **equipment is** expensive.
- She gave me useful **advice**.

주의: 불가산명사는 단수 취급하지만, 일반적인 가산명사의 단수처럼 a/an을 붙이지 않는다.

## 3. 가산명사의 단수와 복수 구별

### 3-1. 단수명사

하나를 나타내는 가산명사이다.

- a/an + 단수 가산명사
- this/that + 단수명사
- each/every + 단수 가산명사

예문
- **A customer** is waiting.
- **Each employee** receives a uniform.
- **Every applicant** must register.

### 3-2. 복수명사

둘 이상을 나타내는 가산명사이다.

- 숫자 2 이상 + 복수명사
- these/those + 복수명사
- many/several/few + 복수명사

예문
- **Three customers** are waiting.
- **Several employees** attended the meeting.
- **These documents** are important.

### 3-3. 단수와 복수 형태 비교

| 단수 | 복수 |
|---|---|
| employee | employees |
| report | reports |
| company | companies |
| box | boxes |
| child | children |
| person | people |
| man | men |
| woman | women |

주의: 불규칙 복수형도 있으므로 단순히 -s만 붙이면 안 되는 경우가 있다.

## 4. 가산명사와 불가산명사 구별법

토익에서는 명사 앞의 수량 표현과 관사를 보고 판단하는 문제가 자주 출제된다.

| 표현 | 가산명사 | 불가산명사 |
|---|---|---|
| a/an | 가능 (단수) | 일반적으로 불가능 |
| many | 가능 | 불가능 |
| much | 불가능 | 가능 |
| a few | 가능 | 불가능 |
| a little | 불가능 | 가능 |
| several | 가능 | 불가능 |
| some | 가능 | 가능 |
| a lot of | 가능 | 가능 |
| plenty of | 가능 | 가능 |
| enough | 가능 | 가능 |

예문
- We received **many applications**.
- We need **much information**.
- There are **a few chairs** available.
- We have **a little time** left.
- We purchased **some equipment**.
- We have **enough resources**.

## 5. 가산명사와 불가산명사 앞의 수량 표현

### 5-1. 가산명사 복수형 앞에 오는 표현

| 표현 | 뜻 | 예시 |
|---|---|---|
| many | 많은 | many employees |
| a few | 몇몇의, 약간의 | a few questions |
| few | 거의 없는 | few applicants |
| several | 몇몇의 | several reports |
| both | 둘 다의 | both companies |
| numerous | 수많은 | numerous requests |
| a number of | 많은 수의 | a number of customers |

### 5-2. 불가산명사 앞에 오는 표현

| 표현 | 뜻 | 예시 |
|---|---|---|
| much | 많은 | much information |
| a little | 약간의 | a little time |
| little | 거의 없는 | little progress |
| a great deal of | 많은 | a great deal of money |
| an amount of | 일정량의 | an amount of work |

### 5-3. 가산명사와 불가산명사 모두 가능한 표현

| 표현 | 가산명사 예시 | 불가산명사 예시 |
|---|---|---|
| some | some documents | some information |
| any | any questions | any advice |
| a lot of | a lot of employees | a lot of work |
| lots of | lots of books | lots of money |
| plenty of | plenty of opportunities | plenty of time |
| enough | enough chairs | enough equipment |
| all | all employees | all information |
| no | no problems | no information |

---

## 6. 단수명사와 복수명사 앞에 오는 수량 표현

| 단수 가산명사 | 복수 가산명사 |
|---|---|
| a/an | many |
| one | a few |
| each | few |
| every | several |
| another | both |
| either | numerous |
| neither | a number of |

예문
- **Each employee** has an ID card.
- **Every applicant** must submit a resume.
- **Both employees** attended the meeting.
- **Several reports** were submitted.
- **Another opportunity** may arise.

주의:
- each/every + 단수 가산명사
- both/several/many + 복수 가산명사
- another + 단수 가산명사
- one of the + 복수명사: One of the **employees** is absent.

## 7. 토익 빈출 함정

### 함정 1. information은 불가산명사

- We need **more information**. (O)
- We need **many informations**. (X)

### 함정 2. equipment는 불가산명사

- The company purchased **new equipment**. (O)
- The company purchased **many equipments**. (X)

### 함정 3. every 뒤에는 단수 가산명사

- Every **employee** must attend. (O)
- Every **employees** must attend. (X)

### 함정 4. a few와 a little 구별

- a few + 복수 가산명사
- a little + 불가산명사

예시
- a few **questions**
- a little **money**

### 함정 5. many와 much 구별

- many + 복수 가산명사
- much + 불가산명사

예시
- many **applications**
- much **research**

### 함정 6. 수량 표현과 동사 수 일치

- A number of employees **are** attending.
- The number of employees **is** increasing.

**a number of + 복수명사 + 복수동사**: 많은 ~
**the number of + 복수명사 + 단수동사**: ~의 수

## 8. 시험 직전 암기 요약

1. 명사 자리에는 명사가 와야 한다.
2. 가산명사 단수에는 일반적으로 a/an, one, each, every 등을 사용한다.
3. 가산명사 복수에는 many, a few, several, both 등을 사용한다.
4. 불가산명사에는 much, a little, an amount of 등을 사용한다.
5. some, any, a lot of, enough는 가산·불가산명사 모두 가능하다.
6. 불가산명사는 일반적으로 복수형 -s를 붙이지 않는다.
7. each/every + 단수명사, many/several + 복수명사.
8. a few + 복수 가산명사, a little + 불가산명사.
9. many + 복수 가산명사, much + 불가산명사.
10. a number of는 복수 취급, the number of는 단수 취급한다.
