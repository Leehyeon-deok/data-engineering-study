# TOEIC Part 5 문법 정리 — 품사·to부정사·동명사

## 1. 문장 성분과 품사 구분

토익 Part 5에서 빈칸 문제를 풀 때는 먼저 **빈칸이 문장에서 어떤 역할을 하는지** 확인한다.

### 1-1. 주어 자리

주어 자리에는 일반적으로 명사 역할을 하는 표현이 온다.

| 품사·형태 | 예시 | 가능 여부 |
|---|---|---|
| 명사 | Application is required. | O |
| 동명사 | Drinking water is important. | O |
| to부정사 | To exercise regularly is beneficial. | O |
| 동사원형 | Drink water is important. | X |
| 형용사 | Different is important. | X |

**예제 1**

The company requires an ______ from all applicants.

- (A) apply
- (B) application
- (C) applicable
- (D) applying

정답: **(B) application**

해설: 관사 `an` 뒤에 명사가 필요하다. `apply`는 동사, `application`은 명사다.

**예제 2**

(Drinking / Drink) enough water is important.

정답: **Drinking**

해설: `Drinking enough water` 전체가 주어 역할을 한다. 여기서 `Drinking`은 동명사다.

**예제 3**

The company needs a ______ solution.

- (A) differ
- (B) difference
- (C) different
- (D) differently

정답: **(C) different**

해설: `solution`이라는 명사를 꾸며야 하므로 형용사가 필요하다.

주의: 주어 자리에 명사뿐 아니라 동명사구와 to부정사구도 올 수 있다.

### 1-2. 동사 자리

동사 자리는 문장의 서술어 역할을 하는 동사가 필요하다.

| 선택지 형태 | 예시 | 판단 |
|---|---|---|
| 동사 | The manager **reviews** the report. | O |
| to부정사 | The manager to review the report. | X (일반적인 완전한 문장 기준) |
| 동명사 | The manager reviewing the report. | X (일반적인 완전한 문장 기준) |
| 명사 | The manager review of the report. | X |

단, to부정사와 동명사는 문장 내에서 주어·목적어 등으로 쓰일 수 있다. 동사 자리에 올 수 없다는 말은 **문장의 본동사 자리에 그대로 쓸 수 없다는 의미**다.

동사 자리 문제는 다음 순서로 확인한다.

1. 주어가 있는지 확인한다.
2. 문장에 본동사가 있는지 확인한다.
3. 시제와 수 일치를 확인한다.
4. 능동태인지 수동태인지 확인한다.

예시:

The manager ______ the report every Monday.

- (A) review
- (B) reviews
- (C) reviewing
- (D) reviewable

정답: **(B) reviews**

### 1-3. 명사·형용사·부사 구별

| 품사 | 역할 | 예시 |
|---|---|---|
| 명사 | 사람·사물·개념 | application, difference |
| 동사 | 동작·상태 | apply, differ |
| 형용사 | 명사 수식 또는 보어 | applicable, different |
| 부사 | 동사·형용사·문장 수식 | differently, carefully |

자주 헷갈리는 단어:

| 동사 | 명사 | 형용사 | 부사 |
|---|---|---|---|
| apply | application | applicable | — |
| differ | difference | different | differently |
| decide | decision | decisive | decisively |
| succeed | success | successful | successfully |
| inform | information | informative | informatively |
| compete | competition | competitive | competitively |

암기 포인트:
- 관사(a, an, the) 뒤에는 명사가 자주 온다.
- 명사 앞에는 형용사가 자주 온다.
- 일반동사 뒤에는 부사가 자주 온다.
- be동사 뒤에는 형용사가 올 수 있다.

## 2. to부정사를 목적어로 취하는 동사

형태: **동사 + to + 동사원형**

| 동사 | 뜻 | 토익 형태 |
|---|---|---|
| ⭐ want | 원하다 | want to do |
| ⭐ hope | 바라다 | hope to do |
| ⭐ wish | 바라다 | wish to do |
| ⭐ decide | 결정하다 | decide to do |
| ⭐ plan | 계획하다 | plan to do |
| ⭐ expect | 기대하다 | expect to do |
| ⭐ agree | 동의하다 | agree to do |
| ⭐ promise | 약속하다 | promise to do |
| ⭐ refuse | 거절하다 | refuse to do |
| ⭐ offer | 제안하다 | offer to do |
| ⭐ choose | 선택하다 | choose to do |
| ⭐ manage | 가까스로 해내다 | manage to do |
| ⭐ afford | ~할 여유가 있다 | afford to do |
| ⭐ fail | ~하지 못하다 | fail to do |
| ⭐ learn | 배우다 | learn to do |
| ⭐ intend | 의도하다 | intend to do |
| ⭐ tend | ~하는 경향이 있다 | tend to do |
| ⭐ appear | ~인 것 같다 | appear to do |
| ⭐ seem | ~인 것 같다 | seem to do |
| prepare | 준비하다 | prepare to do |
| attempt | 시도하다 | attempt to do |
| demand | 요구하다 | demand to do |
| deserve | ~할 가치가 있다 | deserve to do |
| hesitate | 망설이다 | hesitate to do |
| determine | 결심하다 | determine to do |
| struggle | 애쓰다 | struggle to do |
| volunteer | 자원하다 | volunteer to do |
| claim | 주장하다 | claim to do |

예문:

- We decided to launch a new product.
- She agreed to attend the meeting.
- The company failed to meet its target.

추가 암기:
- prepare to do: ~할 준비를 하다
- prepare for + 명사: ~을 준비하다

| ⭐ finish | 끝내다 | finish doing |
| ⭐ avoid | 피하다 | avoid doing |
| ⭐ consider | 고려하다 | consider doing |
| ⭐ suggest | 제안하다 | suggest doing |
| ⭐ recommend | 추천하다 | recommend doing |
| ⭐ postpone | 연기하다 | postpone doing |
| ⭐ delay | 지연시키다 | delay doing |
| ⭐ deny | 부인하다 | deny doing |
| ⭐ mind | 꺼리다 | mind doing |
| ⭐ practice | 연습하다 | practice doing |
| ⭐ admit | 인정하다 | admit doing |
| ⭐ appreciate | 감사하다 | appreciate doing |
| ⭐ miss | 놓치다·그리워하다 | miss doing |
| ⭐ quit | 그만두다 | quit doing |
| ⭐ keep | 계속하다 | keep doing |
| ⭐ give up | 포기하다 | give up doing |
| ⭐ imagine | 상상하다 | imagine doing |
| ⭐ risk | 위험을 감수하다 | risk doing |
| ⭐ resist | 저항하다 | resist doing |

예문:

- Please avoid making unnecessary changes.
- We finished reviewing the report.

주의:
- suggest doing: ~하는 것을 제안하다

- 일반적으로 suggest to do 형태로 쓰지 않는다.

## 4. to부정사와 동명사 모두 가능한 동사

### 4-1. 형태에 따라 의미가 달라지는 동사

| 동사 | to부정사 | 동명사 |
|---|---|---|
| remember | 앞으로 할 일을 기억하다 | 과거에 한 일을 기억하다 |
| forget | 앞으로 할 일을 잊다 | 과거에 한 일을 잊다 |
| regret | 앞으로 할 일을 유감스럽게 여기다 | 과거에 한 일을 후회하다 |
| stop | ~하기 위해 멈추다 | ~하는 것을 멈추다 |
| try | ~하려고 노력하다 | 시험 삼아 ~해 보다 |
| mean | ~할 의도이다 | ~을 의미하다·수반하다 |
| go on | 이어서 다른 일을 하다 | 같은 일을 계속하다 |

예문:

- I stopped to smoke. → 담배를 피우기 위해 멈췄다.
- I stopped smoking. → 담배 피우는 것을 그만뒀다.
- Remember to call him. → 그에게 전화할 것을 기억해.
- I remember calling him. → 그에게 전화했던 것을 기억해.

### 4-2. 두 형태 모두 자주 쓰이는 동사

| 동사 | 형태 |
|---|---|
| ⭐ begin | begin to do / doing |
| ⭐ start | start to do / doing |
| ⭐ continue | continue to do / doing |
| ⭐ like | like to do / doing |
| ⭐ love | love to do / doing |
| ⭐ hate | hate to do / doing |
| ⭐ prefer | prefer to do / doing |

처음에는 두 형태 모두 가능하다는 점을 익히고, 의미 차이가 중요한 동사부터 구분한다.

## 5. 전치사 뒤에는 명사 또는 동명사

기본 형태: **전치사 + 명사 / 동명사(-ing)**

| 전치사 표현 | 뜻 | 예문 |
|---|---|---|
| ⭐ before | ~하기 전에 | before leaving |
| ⭐ after | ~한 후에 | after completing |
| ⭐ by | ~함으로써 | by using |
| ⭐ without | ~하지 않고 | without asking |
| ⭐ instead of | ~하는 대신에 | instead of buying |
| ⭐ in addition to | ~에 더하여 | in addition to working |
| ⭐ look forward to | ~을 기대하다 | look forward to meeting |
| ⭐ be interested in | ~에 관심이 있다 | interested in learning |
| ⭐ be responsible for | ~을 책임지다 | responsible for managing |
| ⭐ be capable of | ~할 능력이 있다 | capable of handling |
| ⭐ be committed to | ~에 전념하다 | committed to improving |
| ⭐ object to | ~에 반대하다 | object to changing |
| ⭐ be accustomed to | ~에 익숙하다 | accustomed to working |
| ⭐ contribute to | ~에 기여하다 | contribute to improving |
| ⭐ succeed in | ~에 성공하다 | succeed in completing |
| ⭐ insist on | ~을 고집하다 | insist on paying |
| ⭐ apologize for | ~에 대해 사과하다 | apologize for being late |
| ⭐ prevent A from | A가 ~하는 것을 막다 | prevent him from leaving |
| ⭐ be dedicated to | ~에 헌신하다 | dedicated to helping |
| ⭐ be used to | ~에 익숙하다 | used to working |

### to 구별하기

- want to work → to부정사 + 동사원형
- look forward to meeting → 전치사 to + 동명사
- be committed to improving → 전치사 to + 동명사

추가로 구별할 표현:

- used to do: 과거에 ~하곤 했다
- be used to doing: ~하는 데 익숙하다

## 6. 목적어 뒤에 to부정사가 오는 동사

형태: **동사 + 목적어 + to + 동사원형**

| 동사 | 뜻 | 예문 형태 |
|---|---|---|
| ⭐ ask | 요청하다 | ask him to help |
| ⭐ tell | 말하다·시키다 | tell him to wait |
| ⭐ want | 원하다 | want him to attend |
| ⭐ allow | 허락하다 | allow employees to leave |
| ⭐ encourage | 장려하다 | encourage staff to participate |
| ⭐ expect | 기대하다 | expect him to finish |
| ⭐ require | 요구하다 | require applicants to submit |
| ⭐ invite | 초대하다 | invite her to join |
| ⭐ remind | 상기시키다 | remind him to call |
| ⭐ advise | 조언하다 | advise employees to apply |
| ⭐ persuade | 설득하다 | persuade him to agree |
| ⭐ enable | 가능하게 하다 | enable users to access |
| ⭐ permit | 허가하다 | permit visitors to enter |
| ⭐ force | 강요하다 | force him to resign |
| ⭐ instruct | 지시하다 | instruct staff to follow |

예문:

The manager asked employees to submit the report.

- asked: 동사
- employees: 목적어
- to submit: 목적격 보어

이때는 ask to do가 아니라 **ask + 사람 + to do** 구조를 익힌다.

## 7. 동사원형이 오는 표현

| 표현 | 형태 | 예문 |
|---|---|---|
| ⭐ make + 목적어 | 동사원형 | make him work |
| ⭐ let + 목적어 | 동사원형 | let him leave |
| ⭐ have + 목적어 | 동사원형 | have him check |
| ⭐ help + 목적어 | 동사원형 또는 to부정사 | help him (to) finish |
| ⭐ had better | 동사원형 | had better leave |
| ⭐ would rather | 동사원형 | would rather stay |

주의: 수동태에서는 다음처럼 바뀐다.

- 능동: They made him work.
- 수동: He was made to work.

## 10. Part 5 빈칸 풀이 순서

1. 빈칸의 위치를 확인한다.
2. 주어·동사·목적어 등 문장 성분을 파악한다.
3. 명사·동사·형용사·부사 중 필요한 품사를 판단한다.
4. 동사 뒤라면 to부정사, 동명사, 목적어 + to부정사 구조를 확인한다.
5. 전치사 뒤라면 명사 또는 동명사가 오는지 확인한다.
6. 마지막으로 문맥과 해석을 확인한다.

### 핵심 요약

- 주어 자리: 명사, 동명사구, to부정사구 가능
- 본동사 자리: 문장에 맞는 동사의 형태 필요
- 명사 앞: 형용사가 자주 옴
- 전치사 뒤: 명사 또는 동명사
- want to do / enjoy doing
- ask + 사람 + to do
- make + 목적어 + 동사원형
- look forward to doing

**공부 방법:** 하루 10개씩 전치사·동사 어구를 암기하고, Part 5 문제를 풀 때 정답 근거를 한 줄로 적는다.
