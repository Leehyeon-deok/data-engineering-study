# TOEIC RC - Conjunctions (접속사)

## 1. 접속사란?

접속사는 단어와 단어, 구와 구, 절과 절을 연결하는 역할을 한다.

- **등위접속사**: 대등한 요소를 연결
- **상관접속사**: 짝을 이루어 요소를 연결
- **종속접속사**: 종속절을 이끌어 주절과 연결

### 기본 개념: 절(Clause)

- **주어 + 동사**가 있으면 절이다.
- 접속사 뒤에 `주어 + 동사`가 오는지 확인하는 것이 중요하다.

---

## 2. 등위접속사 (Coordinating Conjunctions)

서로 대등한 단어, 구, 절을 연결한다.

### 대표 접속사: FANBOYS

| 접속사 | 뜻 | 예문 |
|---|---|---|
| **F**or | 왜냐하면, ~이므로 | We stayed inside, for it was raining. |
| **A**nd | 그리고 | Tom and Jane work here. |
| **N**or | ~도 아니다 | He doesn't smoke, nor does he drink. |
| **B**ut | 그러나 | The product is cheap but effective. |
| **O**r | 또는 | Call me or send an email. |
| **Y**et | 그러나, 그럼에도 | It was difficult, yet she succeeded. |
| **S**o | 그래서 | It was late, so we left. |

### 토익 핵심

- 명사 + and/or/but + 명사
- 형용사 + and/or/but + 형용사
- 동사 + and/or/but + 동사
- 완전한 문장 + 접속사 + 완전한 문장

**예문**

The manager is experienced **and** reliable.

→ experienced와 reliable이라는 형용사를 연결한다.

The meeting was canceled, **so** we returned home.

→ 두 개의 절을 연결한다.

### 주의할 점

등위접속사 뒤에 항상 주어와 동사가 오는 것은 아니다. 단어끼리 연결할 수도 있다.

## 3. 상관접속사 (Correlative Conjunctions)

짝을 이루어 서로 대등한 요소를 연결한다.

| 상관접속사 | 뜻 | 예문 |
|---|---|---|
| **both A and B** | A와 B 둘 다 | Both Tom and Jane are attending. |
| **either A or B** | A 또는 B 둘 중 하나 | You can either call or email us. |
| **neither A nor B** | A도 B도 아닌 | Neither Tom nor Jane is available. |
| **not A but B** | A가 아니라 B | It is not expensive but practical. |
| **not only A but also B** | A뿐만 아니라 B도 | She is not only skilled but also efficient. |
| **whether A or B** | A인지 B인지 | We must decide whether to stay or leave. |
| **rather A than B** | B라기보다 A | He is a leader rather than a manager. |

### 토익 핵심 1: 짝을 기억하기

- both ↔ and
- either ↔ or
- neither ↔ nor
- not only ↔ but also
- whether ↔ or

짝의 앞부분이 주어지면 뒤에 올 접속사를 찾는 문제가 자주 나온다.

### 토익 핵심 2: 병렬 구조

상관접속사는 양쪽에 같은 문법 형태를 연결하는 것이 기본이다.

- 명사 + 명사
- 형용사 + 형용사
- 동사원형 + 동사원형
- 동명사 + 동명사
- to부정사 + to부정사

**올바른 예문**

The job requires both **experience and skill**.

→ 명사 + 명사

She is not only **intelligent but also diligent**.

→ 형용사 + 형용사

He likes both **reading and writing**.

→ 동명사 + 동명사

### 토익 핵심 3: 주어와 동사의 수 일치

**both A and B + 복수 동사**

Both the manager and the employee **are** present.

**either A or B / neither A nor B**

주어가 되는 A와 B의 수가 다르면 일반적으로 동사에 가까운 주어에 수를 일치시킨다.

Neither the manager nor the employees **are** available.

→ 가까운 주어 employees가 복수이므로 are

Either the employees or the manager **is** responsible.

→ 가까운 주어 manager가 단수이므로 is

## 4. 종속접속사 (Subordinating Conjunctions)

종속접속사는 부사절 등을 이끌어 주절과 연결한다.

### 4-1. 시간

| 접속사 | 뜻 |
|---|---|
| when | ~할 때 |
| while | ~하는 동안 |
| before | ~하기 전에 |
| after | ~한 후에 |
| until | ~할 때까지 |
| since | ~한 이후로 |
| as soon as | ~하자마자 |
| once | 일단 ~하면 |

**예문**

Please contact me **when you arrive**.

→ 네가 도착하면 연락해 줘.

### 4-2. 이유

| 접속사 | 뜻 |
|---|---|
| because | ~이기 때문에 |
| since | ~이므로 |
| as | ~이므로 |

**예문**

The event was canceled **because it rained**.

→ 비가 왔기 때문에 행사가 취소되었다.

### 4-3. 조건

| 접속사 | 뜻 |
|---|---|
| if | 만약 ~라면 |
| unless | ~하지 않는 한 |
| as long as | ~하는 한 |
| provided (that) | ~라는 조건으로 |
| in case | ~할 경우에 대비하여 |

**예문**

You can enter **if you have a ticket**.

→ 표가 있으면 입장할 수 있다.

### 4-4. 양보·대조

| 접속사 | 뜻 |
|---|---|
| although | 비록 ~이지만 |
| though | 비록 ~이지만 |
| even though | 비록 ~일지라도 |
| whereas | ~인 반면에 |
| while | ~인 반면에 |

**예문**

**Although the product is expensive**, it sells well.

→ 그 제품은 비싸지만 잘 팔린다.

### 4-5. 목적·결과

| 접속사 | 뜻 |
|---|---|
| so that | ~할 수 있도록 |
| in order that | ~하기 위해서 |
| such that | 그 결과 ~하도록 (문맥에 따라) |

**예문**

We left early **so that we could arrive on time**.

→ 제시간에 도착할 수 있도록 일찍 출발했다.

### 4-6. 양태·비교

| 접속사 | 뜻 |
|---|---|
| as if | 마치 ~인 것처럼 |
| as though | 마치 ~인 것처럼 |
| than | ~보다 |
| as ... as | ~만큼 ...한 |

**예문**

He talks **as if he knows everything**.

→ 그는 마치 모든 것을 아는 것처럼 말한다.

## 5. 토익 최중요 구분: 접속사 vs 전치사

접속사와 전치사는 뜻이 비슷해도 뒤에 오는 구조가 다르다.

| 접속사 | 전치사 | 뜻 |
|---|---|---|
| because + 주어 + 동사 | because of + 명사 | ~ 때문에 |
| although + 주어 + 동사 | despite + 명사 | ~에도 불구하고 |
| while + 주어 + 동사 | during + 명사 | ~하는 동안 |
| if + 주어 + 동사 | in case of + 명사 | ~할 경우 |
| whereas + 주어 + 동사 | unlike + 명사 | ~와 달리 |

### 암기 공식

- **접속사 + 주어 + 동사**
- **전치사 + 명사(구)**

**예문 1**

The flight was delayed **because it was snowing**.

→ because + 주어 + 동사

The flight was delayed **because of the snow**.

→ because of + 명사

**예문 2**

**Although the deadline was close**, we finished the project.

→ although + 주어 + 동사

**Despite the short deadline**, we finished the project.

→ despite + 명사구

주의: 전치사 뒤에는 명사뿐 아니라 대명사나 동명사도 올 수 있다.

## 6. 토익 빈출 함정

### ① 접속사 뒤에 주어 + 동사가 있는가?

The manager canceled the meeting (because / because of) the speaker was sick.

정답: **because**

→ the speaker was sick는 주어 + 동사가 있는 절이다.

### ② 짝을 이루는 접속사 찾기

The company offers (both / either) training and mentoring.

정답: **both**

→ both A and B

### ③ 병렬 구조 확인

The position requires not only experience but also **(creative / creativity)**.

정답: **creativity**

→ experience와 creativity는 모두 명사이다.

### ④ 종속접속사와 등위접속사 구분

I was tired, **but** I continued working.

→ but은 등위접속사

**Although** I was tired, I continued working.

→ although는 종속접속사

### ⑤ 의미가 비슷한 표현 구분

- because + 절
- because of + 명사구
- although + 절
- despite / in spite of + 명사구
- while + 절
- during + 명사구

## 7. 시험 직전 암기 요약

| 구분 | 핵심 | 대표 표현 |
|---|---|---|
| 등위접속사 | 대등한 요소 연결 | and, but, or, so |
| 상관접속사 | 짝으로 연결 | both A and B |
| 종속접속사 | 종속절 연결 | because, although, if, when |
| 접속사 | 뒤에 절이 올 수 있음 | because + S + V |
| 전치사 | 뒤에 명사구 등이 옴 | because of + N |
| 병렬 구조 | 양쪽 형태를 맞춤 | both reading and writing |

**문제 풀이 순서**

1. 빈칸 뒤에 주어 + 동사가 있는지 확인한다.
2. 접속사인지 전치사인지 구분한다.
3. 상관접속사의 짝을 확인한다.
4. 연결되는 양쪽의 문법 형태가 같은지 확인한다.
5. 문맥에 맞는 뜻을 고른다.
