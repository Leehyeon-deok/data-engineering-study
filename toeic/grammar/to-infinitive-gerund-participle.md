# To-Infinitive, Gerund, and Participle

## 1. To부정사 (To-Infinitive)

### 1-1. 기본 형태
- 형태: `to + 동사원형`
- 의미: ~하는 것, ~하기 위해, ~할

### 1-2. To부정사의 역할

| 역할 | 설명 | 예문 |
|---|---|---|
| 명사적 용법 | ~하는 것 | To exercise is important. |
| 형용사적 용법 | ~할, ~하는 | I have work to do. |
| 부사적 용법 | ~하기 위해 | I study to pass the exam. |

### 1-3. To부정사를 목적어로 취하는 동사

| 동사 | 뜻 | 예시 |
|---|---|---|
| want | 원하다 | want to buy |
| hope | 바라다 | hope to succeed |
| plan | 계획하다 | plan to expand |
| decide | 결정하다 | decide to apply |
| agree | 동의하다 | agree to participate |
| promise | 약속하다 | promise to help |
| expect | 기대하다 | expect to finish |
| refuse | 거절하다 | refuse to answer |
| offer | 제안하다 | offer to assist |
| need | 필요로 하다 | need to improve |
| choose | 선택하다 | choose to remain |
| learn | 배우다 | learn to operate |
| manage | 가까스로 해내다 | manage to complete |
| afford | ~할 여유가 있다 | afford to buy |

### 1-4. To부정사의 주요 표현

- `in order to + 동사원형`: ~하기 위해
- `so as to + 동사원형`: ~하기 위해
- `be able to + 동사원형`: ~할 수 있다
- `be willing to + 동사원형`: 기꺼이 ~하다
- `be likely to + 동사원형`: ~할 가능성이 있다
- `be required to + 동사원형`: ~하도록 요구받다

## 2. 동명사 (Gerund)

### 2-1. 기본 형태
- 형태: `동사원형 + ing`
- 의미: ~하는 것
- 역할: 명사 역할

예문:
- Swimming is good exercise.
- I enjoy reading books.
- She finished writing the report.

### 2-2. 동명사를 목적어로 취하는 동사

| 동사 | 뜻 | 예시 |
|---|---|---|
| enjoy | 즐기다 | enjoy working |
| finish | 끝내다 | finish writing |
| avoid | 피하다 | avoid making |
| mind | 꺼리다 | mind waiting |
| consider | 고려하다 | consider applying |
| suggest | 제안하다 | suggest changing |
| recommend | 추천하다 | recommend using |
| postpone | 연기하다 | postpone holding |
| deny | 부인하다 | deny taking |
| admit | 인정하다 | admit making |
| practice | 연습하다 | practice speaking |
| quit | 그만두다 | quit smoking |
| keep | 계속하다 | keep trying |
| appreciate | 감사히 여기다 | appreciate receiving |

### 2-3. 전치사 뒤에는 명사 또는 동명사

전치사 뒤에 동사를 쓰려면 동명사 형태를 사용한다.

| 표현 | 의미 |
|---|---|
| before leaving | 떠나기 전에 |
| after reviewing | 검토한 후에 |
| without saying | 말하지 않고 |
| by using | 사용함으로써 |
| instead of buying | 구매하는 대신에 |
| interested in learning | 배우는 것에 관심이 있는 |
| responsible for managing | 관리하는 것을 책임지는 |
| look forward to meeting | 만나기를 기대하다 |
| be committed to improving | 개선하는 데 전념하다 |

주의:
- `want to study`: to부정사 + 동사원형
- `look forward to studying`: 전치사 to + 동명사
- `be used to working`: ~하는 데 익숙하다
- `used to work`: 과거에 ~하곤 했다

## 3. To부정사와 동명사를 모두 취하는 동사

### 3-1. 의미 차이가 거의 없는 동사

| 동사 | To부정사 | 동명사 |
|---|---|---|
| like | like to read | like reading |
| love | love to travel | love traveling |
| hate | hate to wait | hate waiting |
| begin | begin to work | begin working |
| start | start to rain | start raining |
| continue | continue to improve | continue improving |

### 3-2. 형태에 따라 의미가 달라지는 동사

| 동사 | To부정사 | 동명사 |
|---|---|---|
| remember | 앞으로 할 일을 기억하다 | 과거에 한 일을 기억하다 |
| forget | 해야 할 일을 잊다 | 했던 일을 잊다 |
| stop | ~하기 위해 멈추다 | ~하는 것을 그만두다 |
| try | 노력하다 | 시험 삼아 해보다 |
| regret | 유감스럽게도 ~하게 되다 | ~한 것을 후회하다 |

예문:
- I remembered to call him.  
  → 그에게 전화해야 한다는 것을 기억했다.
- I remember calling him.  
  → 그에게 전화했던 것을 기억한다.
- He stopped to rest.  
  → 쉬기 위해 하던 일을 멈췄다.
- He stopped smoking.  
  → 흡연을 그만뒀다.

## 4. 분사 (Participle)

### 4-1. 분사의 종류

분사는 동사에서 파생되며 형용사처럼 명사를 수식하거나 보어 역할을 한다.

| 구분 | 형태 | 의미 | 예시 |
|---|---|---|---|
| 현재분사 | 동사원형 + ing | 능동, 진행 | an interesting book |
| 과거분사 | 동사의 p.p. | 수동, 완료 상태 | a broken window |

핵심:
- 현재분사: 명사가 직접 행동하거나 어떤 감정을 일으키는 경우
- 과거분사: 명사가 행동을 당하거나 어떤 영향을 받은 경우

### 4-2. 현재분사와 과거분사 구별

| 현재분사 (-ing) | 과거분사 (p.p.) |
|---|---|
| interesting: 흥미로운 | interested: 흥미를 느끼는 |
| exciting: 흥미진진한 | excited: 신이 난 |
| boring: 지루하게 만드는 | bored: 지루함을 느끼는 |
| surprising: 놀라운 | surprised: 놀란 |
| satisfying: 만족감을 주는 | satisfied: 만족한 |
| confusing: 혼란스럽게 만드는 | confused: 혼란스러워하는 |
| disappointing: 실망스러운 | disappointed: 실망한 |
| tiring: 피곤하게 만드는 | tired: 피곤한 |

예문:
- The presentation was interesting.  
  → 발표가 흥미로웠다.
- I was interested in the presentation.  
  → 나는 발표에 흥미를 느꼈다.
- The customers were satisfied with the service.  
  → 고객들은 서비스에 만족했다.

암기:
- `-ing`: 감정을 일으키는 쪽
- `-ed`: 감정을 느끼는 쪽

이 구분은 감정을 나타내는 분사에서 특히 유용하다.

### 4-3. 명사 앞에서 분사가 수식하는 경우

분사는 형용사처럼 명사 앞에서 명사를 수식할 수 있다.

- a growing company: 성장하고 있는 회사
- an exciting event: 흥미진진한 행사
- a damaged product: 손상된 제품
- the attached document: 첨부된 문서
- qualified employees: 자격을 갖춘 직원
- a written report: 작성된 보고서

일반적으로 분사가 다른 말을 함께 이끌어 길어지면 명사 뒤에서 수식할 수도 있다.

- employees working in the office  
  → 사무실에서 근무하는 직원들
- documents submitted yesterday  
  → 어제 제출된 문서들

### 4-4. 분사와 수동태 구별

현재분사와 과거분사는 동사 형태뿐 아니라 문장 구조도 함께 확인해야 한다.

| 구조 | 의미 | 예문 |
|---|---|---|
| be + 현재분사 | 진행 | The staff are preparing the report. |
| be + 과거분사 | 수동 | The report was prepared by the staff. |
| have + 과거분사 | 완료 | The staff have prepared the report. |
| 명사 + 현재분사 | 능동 관계의 수식 | employees attending the meeting |
| 명사 + 과거분사 | 수동 관계의 수식 | documents attached to the email |

주의:
`be + p.p.`가 항상 단순한 동작의 수동태만 의미하는 것은 아니다. 문맥에 따라 상태를 나타낼 수도 있다.

## 5. 분사구문 (Participle Clause)

분사구문은 부사절을 간결하게 줄인 형태다.

### 5-1. 기본 형태

- 능동: `접속사 + 주어 + 동사` → `동사원형 + ing`
- 수동: `접속사 + 주어 + be동사 + p.p.` → `p.p.`

예문:
- After she finished the work, she went home.
- Finishing the work, she went home.  
  → 일을 끝내고 그녀는 집에 갔다.
- Because it was written in English, the document was difficult to understand.
- Written in English, the document was difficult to understand.  
  → 영어로 작성되어 그 문서는 이해하기 어려웠다.

분사구문의 의미는 문맥에 따라 시간, 이유, 조건, 양보 등을 나타낼 수 있다.

## 6. 토익 Part 5 품사 구별 전략

### 6-1. 빈칸의 역할부터 확인

| 문장 구조 | 확인할 내용 |
|---|---|
| 동사 + 빈칸 | 목적어로 to부정사 또는 동명사를 취하는 동사인지 확인 |
| 전치사 + 빈칸 | 명사 또는 동명사인지 확인 |
| be동사 + 빈칸 | 진행형, 수동태, 형용사 보어 등을 구별 |
| 빈칸 + 명사 | 형용사 역할을 하는 분사인지 확인 |
| 명사 + 빈칸 | 뒤에서 명사를 수식하는 분사인지 확인 |

### 6-2. 문제 풀이 예시

1. The company plans _____ its services.
   - 정답: `to expand`
   - 이유: plan 뒤에는 to부정사가 온다.

2. Employees should avoid _____ unnecessary mistakes.
   - 정답: `making`
   - 이유: avoid 뒤에는 동명사가 온다.

3. We look forward to _____ from you.
   - 정답: `hearing`
   - 이유: look forward to의 to는 전치사다.

4. The customers were _____ with the service.
   - 정답: `satisfied`
   - 이유: 고객이 만족을 느끼는 대상이므로 과거분사가 적절하다.

5. The company is looking for _____ employees.
   - 정답 예시: `qualified`
   - 이유: qualified가 employees를 수식한다.

## 7. 최종 암기 요약

| 핵심 규칙 | 기억할 내용 |
|---|---|
| To부정사 | `to + 동사원형` |
| 동명사 | `동사원형 + ing`, 명사 역할 |
| 분사 | `-ing / p.p.`, 형용사 역할 가능 |
| 전치사 뒤 | 명사 또는 동명사 |
| want / plan / decide | to부정사 |
| enjoy / finish / avoid | 동명사 |
| look forward to | 동명사 |
| 현재분사 | 능동·진행, 감정을 일으키는 의미 |
| 과거분사 | 수동·완료 상태, 감정을 느끼는 의미 |
| 빈칸 + 명사 | 형용사 또는 분사 가능성 확인 |

**토익 공부 순서 추천**
1. 동사별 to부정사·동명사 구분 암기
2. 전치사 뒤 동명사 규칙 익히기
3. 현재분사와 과거분사의 의미 차이 익히기
4. 문장 구조를 확인하며 Part 5 문제 반복 풀이
